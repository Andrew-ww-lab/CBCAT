Companion to [architecture-audit.md](architecture-audit.md). Every production Java file was reviewed. Tables show actual declarations (including nested records/interfaces), semantic responsibilities and dependencies. `COMMON` means loadable on both sides, not that every method runs on both sides. Server-only mutation paths retain native server/level checks. All listed surviving files are kept; removals are documented separately.

Targets are compiled against the exact installed dependency versions, not a promise of future ABI stability. `require=0` is used only where a multi-target class legitimately lacks the hook.
