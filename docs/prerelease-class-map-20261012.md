# Current production class and Mixin map - 2026-10-12

Supersedes the inventory counts in the September audit, which remains historical.
163 production Java files; 72 active Mixins (57 common, 15 client), plus their
configuration plugin. All surviving entries are retained; the own-item
BigRocketPayloadMixin was removed in favor of direct factory calls.

Declarations below include inheritance and interfaces. COMMON means loadable on
both sides; gameplay mutations remain server-only. Optional API adapters are
reached through presence checks or dependency plugin discovery. State ownership
notes call out the canonical storage systems rather than treating every field
as another manager. Detailed subsystem review is in the pre-release report.
